# Contributing

Run the source-only profile in `TESTING.md` before proposing a change.
Keep historical result JSON, protocol definitions and evaluation splits
immutable. A new scientific question requires a new experiment identifier,
frozen inputs, fair baseline, declared statistical unit and fresh evaluation.
Report coverage and failure cases alongside accuracy.

Do not submit participant files, per-sample coordinates, credentials, private
review logs or local machine paths. New data access must remain explicit and
separate from the original E1 population. Missing measurements remain missing.
Label synthetic fixtures as software evidence, never basketball validation.
